# Part IV — Platform Runtimes

Part IV covers the four built-in platform runtimes that bring the target machine to life inside the emulator. Each platform simulates the specific hardware or guest environment of a real machine — memory layout, I/O ports, display scanning, keyboard input, speaker output, terminal flow, and disk behavior where needed. The platforms share a common architecture and a set of shared utilities; the chapters cover what is unique to each.
