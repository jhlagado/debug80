# Nucleus documentation

Nucleus 0.1 is the current name for the small, safe language intended for routine programming on the TEC-1.

- [`specification.md`](specification.md) is the working Nucleus 0.1 Language Specification and governs source-language conformance at its current revision.
- [`virtual-machine-specification.md`](virtual-machine-specification.md) is the working Nucleus Virtual Machine 0.1 Specification. It governs bytecode images, execution, services, and backend equivalence; the language specification remains authoritative for source-language meaning.
- [`reviewers-charter.md`](reviewers-charter.md) records the settled project directions, open measurements, and evidence expected from an adversarial review. It guides review work but does not override either specification.
