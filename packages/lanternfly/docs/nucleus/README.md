# Nucleus documentation

Nucleus 0.1 is the current name for the small, safe language intended for routine programming on the TEC-1.

- [`specification.md`](specification.md) is the working Nucleus 0.1 Language Specification and governs source-language conformance at its current revision.
- [`v2.md`](v2.md) is a non-normative architecture hypothesis written under the former V2 working label. It records design rationale but does not override the specification.
- [`v1.md`](v1.md), [`lowering.md`](lowering.md), [`grammar-report.md`](grammar-report.md), and [`review-actions.md`](review-actions.md) are retained as development history or supporting evidence. They may contain superseded assumptions.
- [`session-snapshot.md`](session-snapshot.md) is a temporary restart-safe copy from this design session, not a separate authority.
